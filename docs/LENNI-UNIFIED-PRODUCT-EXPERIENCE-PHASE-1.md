# Lenni Unified Product Experience — Phase 1

**Status:** Implemented presentation phase
**Date:** 10 August 2026

Phase 1 adopts the visible product name **Lenni** across the authenticated
workspace shell. Tables and Pages are the primary workspace destinations,
while saved Views remain tabs inside their Table. **Tell Lenni** is the global
entry into the existing Builder route; it is not a second Builder runtime or a
permanent primary navigation destination.

An empty Business now offers two owner-readable starting routes with equal
prominence:

- Tell Lenni what you need;
- Create manually through the existing Table and Page actions.

The populated Table surface uses the existing generic Table engine with a
business-noun title, dynamic Record count, saved View tabs, compact query
controls, quiet save feedback, direct editing, Record opening and a generic
new-Record row. Smaller laptops retain the labelled sidebar, title, tabs and
primary creation action while allowing the grid to use the available width.

This phase changes presentation and hierarchy only. The existing Table
adapter, operational Record mutation boundary, structural/configuration
boundary and Builder orchestration remain unchanged. No migration, new
primitive, AI task, Table engine or frontend framework was added.

Connections, the Record panel, Pages, Builder internals, Changes, Settings,
public experiences and the final mobile workspace remain deferred to later
iterative builds.
