# ADR-044 — Unsaved Saved View preview is a bounded read-only Table query

**Status:** Accepted for Journey 3 I2
**Date:** 22 August 2026

## Context

ADR-039 permits authoritative Table reads only through a persisted trusted View
key. Journey 3 requires an Owner/Admin to inspect an unsaved Saved View's typed
query and exact mixed columns before one coherent save. Persisting a blank View
first would create configuration-history ceremony and violate the one-Version
product contract.

## Decision

Add one authenticated `preview_table_view_records` RPC. It accepts only the
server-derived Business, one active internal source Table key, the existing
bounded `TableViewQuery`, exact bounded mixed columns, and bounded paging.

PostgreSQL requires current Owner/Admin membership, reloads the source Table,
validates canonical Table shape, active same-Business Fields and Connection
orientation, typed operators, Connection multiplicity restrictions, sorting,
grouping and paging, then reads current authoritative Records and edges through
the existing Internal Workspace query helpers. It creates no Change, Version,
Record write, relationship edge, draft row or persisted candidate.

The browser receives no SQL, predicate string, operation list, Business
authority or anonymous/public query capability. Final save independently
recomposes and applies one `configure_saved_view` intent through the existing
atomic direct configuration boundary.

## Consequences

Saved View create/update can commit name, exact ordered columns and typed query
in one immutable Version while preview remains ephemeral. The boundary adds no
table, primitive, query store, public runtime, renderer or configuration
lifecycle. Personal Views, arbitrary expressions, public Record reads and
persistent drafts remain excluded.
